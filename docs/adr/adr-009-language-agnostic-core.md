# ADR-009 语言无关核心

- 状态:accepted

## 背景

代码 Review 产品常以"首批支持语言"划定边界,但真实仓库多语言混杂。

## 决策

核心产品**语言无关**:LLM Review 不设语言白名单;通用读取、搜索、Git、命令执行、测试、构建路径对任意仓库可用。Tree-sitter、LSP、编译器、Linter、SAST 作为**可选插件自动检测**;没有专用插件时仍运行 Review,但 Coverage 必须说明缺少的确定性验证。不以语言划分产品边界。

## 结果

- 任意未知语言仓库仍可被读取、搜索、运行 repo 命令并生成 Review;
- 确定性证据强度随可用插件提升,并在 Coverage 中透明呈现;
- 工具发现优先复用仓库原生命令与 CI 配置。
